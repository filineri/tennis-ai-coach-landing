# TennisAgents Landing Visual Refinement

Use this as a Custom Mode while refining the Landing.

1. Open the Cloudflare branch preview or the local build in Cursor Browser.
2. Use Design Mode to select the exact section/element before changing layout, spacing, hierarchy or motion.
3. Prefer visual simplification over removing product meaning.
4. Preserve the canonical story defined by `@.cursor/rules/landing-visual-refinement.mdc`.
5. Treat Explorer/Strategist, Quick/Detailed/Tracked, living graph, app UI gallery and Real Match Proof as separate visual jobs.
6. Use Browser screenshots at 390, 768, 1440 and 1920 px after each substantive pass.
7. Inspect console and network; no client secret/token may appear.
8. Verify reduced-motion behavior and keyboard focus.
9. Do not convert placeholders into fabricated product screenshots or fabricated match evidence.
10. Before proposing completion run the commands in `@docs/cursor-landing-browser-qa.md` and report evidence, not taste alone.

Do not deploy Production or merge main. Leave release approval to the normal TennisAgents gates.
